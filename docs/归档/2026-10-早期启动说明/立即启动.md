## 📱 开始使用

启动成功后：

1. **创建模板组**
   ```
   系统管理 → 模板管理 → 新建模板组
   ```

2. **上传文档模板**
   ```
   模板详情 → 添加文档 → 选择 Word 文件
   ```

3. **创建项目**
   ```
   项目管理 → 新建项目
   ```

4. **创建文档**
   ```
   项目详情 → 新建文档 → 从模板或上传
   ```

5. **编辑文档**
   ```
   文档列表 → 点击文档 → 进入编辑器
   - 左侧：大纲导航
   - 中间：Markdown 编辑
   - 右侧：实时预览
   ```

6. **导出 Word**
   ```
   编辑器顶部 → 导出 Word 按钮
   ```
