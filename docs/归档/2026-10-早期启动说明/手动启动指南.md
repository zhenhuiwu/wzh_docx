### 方式一：使用增强版启动脚本（推荐）

1. **打开文件资源管理器**
   ```
   路径：D:\项目\智能化

   ```

3. **等待启动**

4. **访问系统**
   ```
   浏览器打开：http://localhost:5173
   ```

### 方式三：命令行启动

#### 1. 打开两个命令行窗口

**窗口 1 - 启动后端**：
```bash
cd D:\项目\智能化\server

# 激活虚拟环境
.venv\Scripts\activate

# 如果虚拟环境不存在，先创建
python -m venv .venv
.venv\Scripts\activate

# 安装依赖
pip install -e .

# 启动后端
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

**窗口 2 - 启动前端**：
```bash
cd D:\项目\智能化\web

# 安装依赖（首次运行）
npm install

# 安装 marked（如果缺失）
npm install marked

# 启动前端
npm run dev
```

#### 2. 访问系统
```
浏览器打开：http://localhost:5173
```

## ⚠️ 常见问题

### 1. 端口被占用

**后端端口 8000 被占用**：
```bash
# 查找占用进程
netstat -ano | findstr :8000

# 杀死进程（替换 PID）
taskkill /PID <进程号> /F
```

**前端端口 5173 被占用**：
```bash
# 查找占用进程
netstat -ano | findstr :5173

# 杀死进程
taskkill /PID <进程号> /F
```

### 2. Python 虚拟环境问题

如果 `.venv` 损坏或不存在：
```bash
cd D:\项目\智能化\server

# 删除旧的虚拟环境
rmdir /s /q .venv

# 重新创建
python -m venv .venv

# 激活并安装
.venv\Scripts\activate
pip install -e .
```

### 3. Node 依赖问题

如果依赖有问题：
```bash
cd D:\项目\智能化\web

# 删除旧的依赖
rmdir /s /q node_modules
del package-lock.json

# 重新安装
npm install
npm install marked
```

### 4. 数据库连接问题

系统默认使用 SQLite（如果配置了 PostgreSQL 才需要检查连接）

如果需要运行迁移：
```bash
cd D:\项目\智能化\server
.venv\Scripts\activate
python -m app.migrate
```

## 📱 使用系统

### 1. 首次访问
访问 http://localhost:5173 后：
- 如果有登录页面，使用默认账号登录
- 如果直接进入系统，可以开始使用

### 2. 创建模板组
```
系统管理 → 模板管理 → 新建模板组
```

### 3. 上传文档模板
```
模板详情 → 添加文档 → 选择 Word 文件
```

### 4. 创建项目
```
项目管理 → 新建项目
```

### 5. 创建文档
```
项目详情 → 新建文档 → 选择模板或上传
```

### 6. 编辑文档
```
文档列表 → 点击文档 → 进入编辑器
```
