# 数据库连接测试和修复

## 测试结果
❌ 数据库连接失败

## 可能的原因

1. **PostgreSQL 服务未启动**
2. **密码不正确**
3. **数据库不存在**
4. **端口不是 5432**

---

## 🔧 快速修复步骤

### 步骤 1：启动 PostgreSQL 服务

**Windows 服务方式**：
```
1. 按 Win + R
2. 输入：services.msc
3. 找到：postgresql-x64-15 (或类似名称)
4. 右键 → 启动
```

**或命令行**：
```bash
net start postgresql-x64-15
```

### 步骤 2：测试连接

打开 pgAdmin 或命令行工具，测试能否连接。

### 步骤 3：创建数据库

如果数据库不存在：
```sql
CREATE DATABASE doc_workbench;
```

### 步骤 4：修改 .env 配置

如果密码不是 `postgres`，编辑文件：
```
D:\项目\智能化\server\.env
```

修改这一行（替换你的实际密码）：
```
DATABASE_URL=postgresql://postgres:你的密码@localhost:5432/doc_workbench
```
