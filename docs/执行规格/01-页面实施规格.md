### 0.2 查询、表单与状态的共同实现

- **Q 查询**：名称参数 `name`；输入不即时查询，点“查询”或非输入法组合态Enter提交，非空条件AND。查询/重置置 `page=1`，重置立即查空条件；`pageSize=10`，可选10/20/50，最大50。总数与行同条件，忽略迟到响应；换查询清选择，翻页沿已提交条件。默认 `sort=updatedAt_desc`，审计按发生时间、检索按相关性。返回恢复条件/页码/滚动，末页失效回有效页。
- **F 字段**：名称trim后1—120字符；说明≤2000；账号1—64、字符规则取身份合同。错误关联label并聚焦首项。`periodStart/periodEnd`均可null；都有值才校验结束不早于开始。省略/清空按合同，不把空串一律转null。正文/提示词/消息限长各取合同。
- **R 权限**：身份/角色/范围/动作从API读取，不信localStorage；无阅读权不露摘要，无操作权隐藏入口，缺条件禁用并解释。服务端复核能力及项目范围；403不重试并清除撤权正文，401重新认证，不本地缓存正文或秘密。
- **S 状态**：首载保留标题/区域，刷新留旧内容并标“正在刷新”；失败标范围并可重试，不装成空列表。提交只禁冲突操作，成功才收表单；超时先核实是否生效，不盲重发。无配置不假成功。
- **U1 脏表单**：换页、换对象或收起前，页内显示“保存后离开／放弃修改／继续编辑”；保存失败留原处。浏览器刷新/关闭用原生离开保护。版本冲突保留本地稿和远端稿、显示差异，不自动覆盖。**U0**：只读或查询无脏数据，无离开拦截。后台任务离页继续，重返读取原任务，不重新创建。
- **键盘**：原生语义控件，展开/收起返回焦点，错误可见并播报，禁用原因常显；不靠全局裁剪隐藏溢出。

| 状态对象 | 共用口径，禁止页面另造枚举 |
|---|---|
| 项目 | `not_started/active/paused/completed`＝未开始/进行中/已暂停/已完成；`archivedAt`独立 |
| 文档 | `state=preparing/draft/pending_review/ready/published`＝准备中/编写中/待审核/可交付/已发布；修订草稿/待审核/已批准/已退回另列 |
| 有效性 | `validity=current/needs_review/conflict`＝当前有效/待复核/存在冲突；问题独立，不覆盖文档状态 |
| 用户/成员 | 用户字段 `account/name/department/globalRoles/status`，`active/disabled`＝启用/停用；成员 `role=owner/editor/reviewer/viewer`＝负责人/编写者/审核者/查看者 |
| 知识资料 | 已上传/解析中/待处理/待发布/已发布/失败/停用；库启用与归档、资料版本、解析世代分别管理 |
| 任务 | 采用08补充的 `queued/running/waiting_input/pause_requested/paused/cancel_requested/needs_verification/succeeded/failed/cancelled`；结果待核实优先于停止终态 |
| 内容采用 | 候选修订≠当前工作稿≠已批准版；任务成功不等于采用、批准或测试通过 |

其余机器值沿既有补充及主合同；未知值显示“状态待核对”并禁变更，不在页面另造枚举。
