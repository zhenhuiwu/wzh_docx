## 2. 视觉与信息组织

服务编写人员、测试人员、审核人员和管理员；核心对象是项目、文档内容块、证据、版本、待办。采用“任务列表进入、内容与依据并列”的工作界面，不以聊天或统计大屏作为唯一入口。拒绝装饰 Landing、假 KPI、渐变英雄区、紫色品牌和新增色板。页面主动作随任务变化，例如“补资料”“审核本块”，不是始终突出“生成全部”。

唯一视觉来源为 [base.css](D:/项目/智能化/web/src/styles/base.css)：

| 页面与文本 | `--desk`、`--sheet`、`--ink`、`--ink-secondary`、`--ink-tertiary` |

| 状态 | `--ok`/`--ok-wash`、`--warn`/`--warn-wash`、`--fault`/`--fault-wash`；必须同时显示状态文字 |

沿用 [console.css](D:/项目/智能化/web/src/styles/console.css)和 [NavItem.vue](D:/项目/智能化/web/src/components/NavItem.vue)；按钮复用 `.primary`、`.ghost`，输入复用 `.control`。复杂编辑优先用页面或页内展开区，不再手写平行 Button/Input/Dialog。若整体换库，只能评审后统一采用 Element Plus 并绑定现有变量；不引入第二套控件，不把 Vue 3 改成 React。旧样式中的硬编码不构成新增值的授权，本次不修改它们。

所有 UI 以名称识别模板和文档，不显示或要求填写编号；内部标识只参与路由、关联和提交。重名用项目、版本、场景辅助区分。旧 DOCX 若有编号栏，是否自动填充业务编号仍待确认；禁止把技术 ID 写入 Word，也不新增编号输入框。

## 3. 六模块导航与路由建议

路径为评审建议，不表示已经实现；动态参数不作为界面可见字段。六个一级入口为工作台、项目管理、用户管理、系统管理、知识库、智能助手。系统管理下保留模板管理，不再增加独立模板一级入口。

| 模块 | 路由与页面组成 |
|---|---|
| 工作台 | `/home`：我的待办、最近项目、需要处理的任务；根路径仍转入此页 |
| 项目管理 | `/projects`：列表及新建；`/projects/:id`：概览、信息及成员；项目下子路径 `documents`、`documents/:documentId`、`materials`、`tests`、`relations`、`reviews`：文档清单/工作台、资料、测试采集、关系变更、审核交付 |
| 用户管理 | `/users`：账号列表及编辑；建议 `/users/roles`：角色授权；`/system/users` 兼容重定向到 `/users`，不保留重复菜单 |
| 系统管理 | 保留 `/system/templates`、`/system/templates/:id`、`/system/settings`；按需新增 `/system/environments`、`/system/rules`、`/system/audit` |
| 知识库 | `/knowledge`：库列表；建议 `/knowledge/:id`：资料、检索、版本与可见范围 |
| 智能助手 | `/assistant`：会话列表及新建；建议 `/assistant/sessions/:id`：对话、任务和产物 |

登录 `/login` 是公共入口；无权限、资源不存在和会话过期使用独立反馈状态。深链刷新、返回列表应恢复筛选、页码和滚动位置。项目子页固定显示项目名称、软件版本和当前位置，切项目先处理未保存修改。

## 4. 全页共用的交互规范

下面各页均必须实现“载/空/错”：加载中保留页面标题与布局；空数据给出可执行下一步，区分无记录和无匹配；出错说明失败范围、保留输入并允许安全重试。不得以空列表掩盖故障，不用固定等待时间伪装加载。状态栏显示实际更新时间，过期结果明确标记。

表单均有 label、必填说明、字段错误、disabled 和提交中状态；首次错误聚焦字段，保留已填内容；异步成功后才关闭编辑区。只禁用冲突操作，不因一个区块请求锁死全页。离开脏表单可保存、放弃或继续编辑；服务端版本冲突先比较，不覆盖他人更改。

列表建议统一“填写条件→查询/Enter→提交条件”，同次条件按且组合；这是相对当前项目页的行为变更，待评审确认。查询回第一页，重置清条件和页码；默认每页十条，可选每页条数待确认。分页、排序、总数必须来自同一条件快照；后发查询不得被先发慢请求覆盖，删除末页最后一条后回有效页。

权限按动作和资源范围呈现，而非只按角色名称：无阅读权隐藏内容和统计；无操作权不展示入口或给出只读说明；有权限但缺前置条件的按钮禁用并解释原因。服务端最终校验；无权深链不得泄露项目名。系统管理员不默认获得全部项目正文权限。下表角色称谓均为职责建议，具体授权边界与业务说明保持一致，并在开发前评审确认。

## 5. 逐页任务与状态

### 5.1 工作台

**主任务：**找到今天需要处理的具体工作，而非浏览宣传信息。可见字段为事项名称、项目、文档名称/内容块、事项类型、更新时间、阻塞原因；最近项目显示名称、负责人、当前状态。

点击待办直达对应块或执行记录，处理后仅按真实结果更新；“新建项目”必须直接打开新建表单。列表按权限过滤，跨项目只聚合允许读取的摘要。载：待办与最近项目分别加载；空：提示“暂无待处理事项”而非“所有文档完成”；错：单区失败不清空其他区。无独立业务表单，筛选遵循共用规范；无创建权不显示新建入口。

### 5.2 项目管理

| 页面／主任务与可见字段 | 核心交互、校验与载/空/错、权限 |
|---|---|
| 项目列表／找项目；名称、负责人、单位、部门、周期、状态、更新时间 | 名称/负责人/部门/状态查询及分页；新建先填名称、负责人、周期，再按名称选择已发布模板集。必填缺失、结束早于开始、名称冲突原位提示。载：列表；空：新建或清筛选；错：保留条件重试。创建、归档分别授权，归档先列运行任务及影响。 |
| 项目概览／确认范围；基本资料、软件版本、成员、角色、缺失事项 | 基本信息和成员页签，添加成员先确认可访问范围；不允许删除最后负责人，移除成员提示其待办移交。载：概览；空：无成员/无文档分别引导；错：权限与保存冲突分开。负责人可维护，其他人按范围只读。 |
| 文档清单／选择工作；名称、模板名称及版本、状态、负责人、待复核原因、更新时间 | 按名称添加文档实例；相同模板可用于不同测试场景，名称需能区分。点名称进工作台；批量发起仅处理明确选中的文档。校验无可用模板、重名、版本不可用。载：清单；空：选择模板；错：显示部分失败。无编辑权仅阅读；已交付版本不可原地修改。 |
| 文档工作台／完成一个块；目录、正文、草稿版本、依据、问题、审核意见 | 单块生成、编辑、保存、比较、提交审核；缺材料定位来源，AI 新稿先比较再采用。空正文显示填写要求；加载失败保留已存稿；保存冲突保留双方版本。锁定或只读块禁编辑，审核权限与编写权限分开。 |
| 项目资料／形成可信事实；材料名称、来源、版本、解析状态、确认状态、引用位置 | 上传材料、提取建议、人工确认公共事实；项目术语统一维护。重复材料、格式不支持、解析失败逐项提示；上游修改预览受影响块。载：材料；空：上传/添加事实；错：重试失败项。草稿不自动成为事实，材料删除受引用和权限约束。 |
| 关系与变更／处理上游影响；变更事项、来源版本、受影响文档/块、原因、责任人、状态 | 从事实或需求定位设计、用例、截图和手册；按项决定修订、重测或记录无需变更理由。载：影响列表；空：无已登记影响，不声称没有任何语义影响；错：保留待复核状态。处理需要对象权限，旧批准版不被删除。 |
| 测试与采集／取得证据；场景、函数或用例名称、环境、软件版本、状态、截图/日志、执行时间 | 三页签：函数测试、界面测试、手册采集。开始前确认范围、账号角色、测试数据和工具权限；步骤/证据可展开。载：记录；空：配置范围；错：区分失败、阻塞、结果待核实。缺环境禁止启动；测试执行权不等于文档编辑权。 |
| 审核与交付／形成可追溯版本；文档/块、差异、问题、审批状态、交付批次、生成环境 | 逐项通过或退回，退回必填原因；导出前显示引用过期、缺证据和排版检查。载：审核/导出分开；空：无待审或无交付；错：定位失败文档并可重试导出。正式交付需审核/发布权限，草稿导出必须显著标记。 |

测试页进一步区分：函数测试展示输入、预期依据、断言与实际结果；功能测试展示步骤、检查点及证据；手册采集展示入口、演示步骤、待用截图和文字映射。功能测试截图可候选复用，但须核对版本、角色、状态和敏感信息。截图不等于通过，测试失败也不等于报告不能编写；报告是否可正式交付按审批规则判断。

执行控制只针对当前任务：暂停显示“请求暂停”，到安全边界后才显示“已暂停”；取消不宣称撤销已发生操作。保存/提交后超时先核实结果，禁止直接重复点击。人工接管须明确停止自动操作，续跑前重新观察。重跑新增记录，原始失败证据保留；重写描述不重跑测试。

### 5.5 知识库

| 页面／主任务与可见字段 | 核心交互、校验与载/空/错、权限 |
|---|---|
| 库列表／找可用材料；名称、简介、项目/组织范围、维护人、更新时间 | 查询分页、创建、归档；创建必须明确可见范围，不默认全员共享。名称为空/冲突提示。载：列表；空：新建或请求授权；错：重试。普通人仅看授权库；不能借库列表得知未授权项目。 |
| 库详情／采集与引用；材料名、版本、来源、解析/索引状态、标签、引用关系 | 上传→解析→检查→可检索；检索结果带来源段落/页码及版本，点引用回原材料。格式/大小限制由服务契约提供；失败逐项重试。载：文件和检索独立；空：无材料/无命中分别提示；错：不得伪装成无结果。上传、维护、共享分别授权；删除前检查引用。 |

检索内容只是参考，需人工确认才进入项目事实。历史项目材料复制须显式授权并保留来源；截图与测试结果不得自动转成新项目证据。共享范围收紧后，检索、助手与旧会话引用同步重新鉴权。

### 5.6 智能助手

| 页面／主任务与可见字段 | 核心交互、校验与载/空/错、权限 |
|---|---|
| 会话入口／恢复工作；项目名称、会话名称、更新时间、任务状态 | 先选项目，再新建或继续；无项目只允许通用咨询，不提供项目写入。载：会话；空：开始对话；错：保留选择。切项目不携带旧材料；无权会话不显示摘要。 |
| 会话详情／多轮完成任务；当前项目/文档/块、已选来源、任务步骤、产物、待确认事项 | 发送前显示任务范围和可能产生的操作；缺材料时定位补充入口。生成结果先持久化为候选，预览比较并显式采用后更新目标块的当前工作稿。载：恢复记录/执行中；空：说明可做什么；错：保留输入、失败步骤与可恢复点。模型未配置禁执行并给设置入口；写入、测试和截图按各自权限确认。 |

同一 Agent 多轮执行，共享当前项目已确认记忆；只展示步骤摘要、工具动作和依据，不展示内部推理。文档面板与完整会话共享任务，不重复启动 Agent。已有写任务时后续指令明确排队或调整，不同时写同一块。清理聊天展示不删除项目事实、证据或执行记录。中文输入法确认文字不得发送；桌面 Enter 发送、Shift+Enter 换行，移动端以发送按钮为准。

## 6. 文档工作台与助手联动线框

以下为结构示意，不是截图或像素级效果承诺。

```text
项目名称 / 文档名称 / 内容块名称       保存状态   [保存草稿] [提交审核]
┌────────────┬──────────────────────┬───────────────────┐
│ 文档目录   │ 当前块：填写要求      │ 依据 / 问题 / 助手│
│ 块名＋状态 │ 已确认版本与当前草稿  │ 项目、文档、块范围│
│ 待复核标记 │ 正文、表格、截图      │ 使用材料和来源版本│
│            │ [生成本块] [比较版本] │ 当前任务、暂停请求│
│            │ 校验问题定位到字段    │ 草稿预览、采用差异│
└────────────┴──────────────────────┴───────────────────┘
```

用户选块→点击生成→确认材料和允许操作→创建任务→后台逐轮处理→校验后存候选修订→比较采用为当前工作稿→提交审核。每轮仅有一个明确目标；材料不足不能自行补成事实。整篇检查只定位问题，不再无边界重写全文。

```text
完整助手：项目名称 / 会话名称     [返回文档] [暂停任务]
会话列表 │ 对话、待确认步骤、工具结果 │ 范围、来源、产物
         │ [查看差异] [定位内容块]    │ 记忆分已确认/待确认
         │ 输入指令 [发送]            │ 最近执行状态
```

“在助手继续”携带同一任务上下文；“返回文档”定位原块及草稿。切块不悄悄改变正在执行任务的目标，应用结果时再次检查目标版本与权限。用户修改过同一块则进入冲突比较；拒绝 AI 草稿不删除原稿或测试记录。

## 7. 响应式与移动端范围

先设计 375，再做 1280，并检查 768、1440。下列数字仅为验收视口，不新增字号、间距或圆角值；布局采用弹性比例及现有变量。

| 视口宽度 | 导航、列表和文档工作台 |
|---|---|
| 375 | 顶栏精简，六模块通过可展开导航进入；主内容单列。查询折叠成有标签的筛选区；列表显示名称、状态、下一步，次要字段展开。目录/正文/依据/助手为切换面板，保留编辑位置。 |
| 768 | 可收起导航；列表保留关键列，详情允许双列表单；工作台正文加一个辅助面板，助手与依据切换，不挤成三窄栏。 |
| 1280 | 常驻导航，常规表格；工作台正文优先，目录与右侧辅助区可收起；长名称换行，工具栏可换行。 |
| 1440 | 三栏并列，建议内容区约为目录一份、正文三份、辅助区一份；限制阅读行宽，额外空间留给依据而非放大字号或假卡片。 |

页面不得横向溢出；宽证据表或 Word 预览仅在自身容器滚动/缩放并给提示，不能靠全局隐藏溢出遮掉按钮。触摸主要控件高度用 `--space-7`，间距仍用已有量级。截图缩略图可打开完整图，不能只依赖悬浮提示阅读。

移动端首版建议支持查项目/待办、读文档和证据、简短编辑评论、知识检索、助手咨询、查看及请求暂停任务。复杂模板提炼、权限矩阵、密钥配置、并排长文审核、代码测试发起与浏览器人工接管建议转桌面；以明确说明和返回路径代替失效按钮。移动端是否允许正式审批、启动自动化任务待批准，不以设备限制替代权限校验。

## 8. 交互需要的业务契约

本节规定交互依赖，具体数据与 API 结构见技术架构说明：

1. 当前身份、项目范围、逐动作能力和禁用原因；分页返回可信总数、应用条件及资源版本。
2. 表单字段约束、重复判定、字段错误和版本冲突；保存明确返回已落库版本，重试不重复创建。
3. 内容块允许输出范围、来源版本、草稿/确认状态、引用过期及差异；界面不自行判断事实成立。
4. 任务状态、持久化进度、可暂停/可取消/可重试动作、确认点和产物；断线重连读取原任务，不当成新任务再执行。
5. 上传限制、解析/索引状态、引用定位、脱敏预览、素材权限；删除或授权变化的影响清单。
6. 测试执行与证据、软件/环境版本、结果待核实状态；导出需模板版本、格式检查结果和可访问文件。在线预览不替代指定 Word/WPS 验收。
