## 一 已明确的硬约束

来自用户需求与仓库固定指令：六个模块；项目内的一组关联文档；现有模板和专属 Skill；块级提示词；一个 Agent 多轮执行与共享项目记忆；本地模型；函数级测试；实际前端操作与截图；用户手册素材采集。

前端使用现有 Vue3 工程。唯一当前本地地址为 http://localhost:5173；改前端必须截图并实际查看，宽度至少 375、768、1440，设计先 375 再 1280。组件只复用现有 .primary/.ghost/.control，未来统一组件库只能 Element Plus。字体、颜色、字号、圆角、间距使用 base.css 已有变量。模板与文档编号不展示、不填写，不增加假统计和 Landing。
