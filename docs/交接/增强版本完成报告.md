## 🔧 技术亮点

### 1. 双向无损转换
```
Word (原始格式)
    ↓ 解析
format_template (JSON)
    ↓ 提取
Markdown (可编辑)
    ↓ 应用
Word (保持格式)
```

### 2. 智能自动保存
- 3秒防抖
- 仅在有更改时保存
- 视觉反馈（● 未保存）
- 不阻塞编辑

### 3. 大纲自动生成
```javascript
const outline = computed(() => {
  const lines = markdownContent.value.split('\n');
  return lines
    .map((line, index) => ({
      level: countHashtags(line),
      text: extractTitle(line),
      line: index
    }))
    .filter(item => item.level > 0);
});
```

### 4. 图片 Base64 嵌入
- 从 Word 提取图片
- Base64 编码存储
- Markdown 中引用
- 导出时解码重建

### 1. 格式模板机制
不是简单的样式转换，而是：
```json
{
  "headings": {
    "1": {
      "font_name": "Microsoft YaHei UI",
      "font_size": 24,
      "bold": true,
      "alignment": "left"
    }
  }
}
```

### 2. 增量自动保存
```javascript
watch(markdownContent, () => {
  clearTimeout(autoSaveTimer.value);
  autoSaveTimer.value = setTimeout(() => {
    if (isDirty.value) save();
  }, 3000);
});
```

### 3. 大纲实时生成
```javascript
const outline = computed(() => 
  markdownContent.value
    .split('\n')
    .map((line, index) => parseHeading(line, index))
    .filter(Boolean)
);
```

### 4. 图片 Base64 流式处理
```python
# 提取 → 编码 → 存储 → 解码 → 重建
```
