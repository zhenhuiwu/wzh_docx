# 文档操作与 Visio

2026年10月4日。Vue 3 前端仍运行在 http://localhost:5173，后端使用 SQLite。

## 本轮已实现

文档编辑工具栏新增“Visio 图表”。可选择流程图或架构图，引用当前章节或整篇文档，填写图表要求。生成后先预览，再下载可编辑的 `.vsdx` 或主动插入正文。已生成图表按文档保存在 SQLite 和文件目录中，重新打开文档仍可读取。

后端使用已配置的 AI 服务规划节点和连接关系，校验结构后调用本机 Microsoft Visio 生成文件。`.vsdx` 中是独立节点和动态连接线。Word 正文插入 PNG；此版本没有嵌入可双击编辑的 Visio OLE 对象。修改源图使用下载的 Visio 文件，在线图表目前通过填写要求重新生成，不支持在线拖动节点或上传修改后的 VSDX。

新增接口在 `server/app/document_diagrams.py`，原生渲染在 `server/app/visio_render.py`，数据库迁移为 `105_document_diagrams.sql`。前端组件为 `web/src/components/DocumentDiagrams.vue`，使用现有控件样式和 CSS token。

## 修复的文档问题

| 问题 | 修复 |
|---|---|
| 3秒自动保存前切换页面，编辑可能丢失 | 离开文档前等待保存；失败阻止离开。浏览器退出有未保存提示 |
| 保存或加载的旧响应影响另一个文档 | 使用文档对象、文档ID和加载序号核对响应，保存请求单次执行 |
| 刷新、断线或冲突后编辑无备份 | 输入时保存浏览器本地副本，按用户和文档隔离；恢复前核对服务器版本，不同版本只允许下载副本核对 |
| 待恢复副本被新输入覆盖 | 处理恢复或舍弃之前锁定编辑及 AI 操作 |
| AI 改写含图片章节时原图被删或导出失败 | 章节和全文草稿必须保留全部原图片标记和顺序；选择文字仍只允许纯文本 |
| 粘贴的新图片保存时静默消失 | 明确阻止不支持的图片粘贴和拖入；原稿图片和受控 Visio 插图可保留、保存、导出 |
| AI 断流后已生成文字被清空 | 保留已收到的部分预览，未完成稿禁止直接采纳 |
| 长图在编辑区显示过大 | 保持比例并限制显示高度；Word 导出按所在分节的纸张和页边距缩放 |
| 重复插入或误用旧图 | 已插入图的按钮禁用；未插入的旧版本图显示核对提示，不自动覆盖正文 |

原稿的图片、域、合并单元格和分节信息仍由导出保护规则管理。无法安全修改时明确报错，不重建整份原稿。编辑视图刷新失败也会锁定旧视图并提供重试，避免继续修改已过期的正文。

## 实际验收

使用独立的中性“订单说明”Word 样本。真实用户文档没有用于 AI 请求或测试写入。

- `npm run build` 通过。
- `test_document_diagrams.py`、`test_docx_export.py`、`test_document_rules.py`、`test_sqlite_runtime.py`、`test_document_memory.py` 合计12项通过。原生图表测试补验含原图及新插图的章节替换，再次执行2项均通过。
- 原生 Visio 重新打开生成文件，核对独立节点、文字及每条动态连接线的两端粘接。接口测试样本为6节点6连接线，真实 AI 流程样本为8节点8连接线；架构样本为4节点3连接线。
- 浏览器真实操作：流程和架构两种生成、下载 Visio、插入正文、刷新、含图章节 AI 改写及采纳、再次下载 Word、版式预览的“下一页”、立即离开时保存、多标签草稿恢复、版本冲突防覆盖、图片粘贴拒绝。
- 本地副本下载已在 Downloads 确认 HTML 文件包含未保存文字和图表，没有脚本。内置浏览器的下载事件工具没有报告 Blob 下载，使用实际生成的文件核对完成。
- 1920×1080 截图逐张查看，检查对齐、焦点环、禁用、空态和错误提示。截图目录：`web/.qa/document-visio-20261004/`，最终图表截图为 `final.png`，恢复锁定截图为 `recovery-desktop.png`。
- 下载的 Word 在本机 Microsoft Word 中打开并渲染全部2页。核对未修改正文、原表格、页眉、styles.xml，流程图完整且没有溢出页面。证据在 `server/.qa-document-visio-20261004/`。
- 中性样本的项目、文档、图表、记忆及文件先存档再从业务数据移出，存档脚本逐一核对UUID、项目标记与绝对路径，业务记录不保留验收样本。

## 当前范围和后续优化

- 生成需要 Windows 上可用的 Microsoft Visio；Word 原生预览需要 Microsoft Word。没有安装时接口明确报告不可用。
- 当前单张图最多24节点、40连接线，采用简单分层布局。复杂跨页图和大量回路需要在 Visio 中进一步整理，不能声称所有复杂图都已通过排版验收。
- 整篇图表引用限16000字，过长会要求缩小至章节，不静默截断。图表规划会读取已采纳的文档写作记忆。
- 本地编辑备份不是文档历史版本。浏览器清理存储后不能依靠它回滚已经保存的版本。
- 下一步优先考虑：保存版本和一键回滚；采纳 AI 前显示修改对比；图表标题、自动编号及正文交叉引用；Word 导出前集中提示未填写项与不支持的排版块。

以上后续项尚未实现，不要把它们描述为当前功能。

原生 Visio 的可编辑结构、连接及导出依据 Microsoft 官方文档：[VSDX 文件格式](https://learn.microsoft.com/en-us/office/client-developer/visio/visio-file-format-reference)、[动态连接线](https://learn.microsoft.com/en-us/office/vba/api/visio.application.connectortooldataobject)、[OpenEx](https://learn.microsoft.com/en-us/office/vba/api/visio.documents.openex)。
