## 📖 使用流程

### 1. 启动系统
```
双击 start_enhanced.bat
→ 等待启动完成
→ 浏览器打开 http://localhost:5173
```

### 2. 创建模板组
```
系统管理 → 模板管理 → 新建模板组
→ 输入：名称、分类、描述
→ 创建成功
```

### 3. 添加文档到模板
```
模板详情 → 添加文档
→ 上传 Word 文件
→ 系统自动解析格式
→ 添加成功
```

### 4. 创建项目文档
```
项目管理 → 项目详情 → 新建文档
→ 选择来源：从模板 / 上传 Word
→ 系统自动解析为 Markdown
→ 创建成功
```

### 5. 编辑文档
```
文档列表 → 点击文档
→ 进入编辑器
→ 左侧：查看大纲
→ 中间：编辑 Markdown
→ 右侧：实时预览
→ 自动保存
```

### 6. 导出 Word
```
编辑器 → 导出 Word 按钮
→ 系统应用格式模板
→ 生成 Word 文档
→ 下载文件
```
