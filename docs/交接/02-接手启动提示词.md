# 接手启动提示词

日期：2026年9月27日。下面内容供用户复制给接手 AI。本文件本身不触发任务、消息、代码执行或自动跟进。

若用户已明确要求开始开发，优先使用 [执行入口末尾的实施指令](D:/项目/智能化/docs/执行规格/00-执行入口.md)，以tasks.json的依赖和文件范围推进，不重新设计六模块。以下核对指令仍适用于尚未给定开发范围的首次接手。

## 一 首轮接手提示词

~~~text
请接手 D:/项目/智能化 的研发文档智能编制系统开发。

先读取 D:/项目/智能化/AGENTS.md，再读 D:/项目/智能化/docs/交接/00-接手AI必读.md，以及其中的方案总览、开发计划和待确认决策；同时核对 D:/项目/智能化/docs/交接/04-开工输入与决策记录.md 与 D:/项目/智能化/docs/完整开发方案/08-开发契约与遗漏补充.md，避免把建议当批准或自行定义不一致的接口状态。涉及前端时，还必须读 D:/项目/智能化/docs/交接/01-前端实现与验收交接.md 和仓库指定的前端技能。

这是已有 Vue3 原型的增量开发，不是新建 React 项目。六模块为工作台、项目管理、用户管理、系统管理、知识库、智能助手。产品采用一个 Agent、共享项目记忆、多轮小任务、按块编写、固定 Word 模板与专属 Skill；测试和截图必须来自真实授权执行。

第一轮先核对实际仓库，区分已实现、仅原型、未实现和待验证，给出最近一个最小可验收任务、依赖、拟修改文件、验收方法及真正阻塞的问题。若我尚未指定本轮开发范围，先完成这份接手报告，不自动实施全部方案、不安装依赖、不改源码或模板。若已有明确批准任务，就按该范围推进，不反复索要相同授权。

遵守固定前端规则：只用现有 Vue3、控件与 CSS 变量；组件库若迁移只允许经批准统一 Element Plus；不展示或填写模板/文档编号；不做假 KPI 和营销页。任何前端修改后必须在 http://localhost:5173 实际操作，在1920×1080固定桌面截图并查看图片；没有实际截图核对不得报完成。

不要把 localStorage 原型、非空即登录、模板本地发布状态或未接入助手当成真实后端能力。保护原始模板和他人修改，不泄漏凭据，不执行未授权产品或生产操作。方案中的技术候选、排期和待确认决策不是自动批准。

每轮按 D:/项目/智能化/docs/交接/03-阶段交付与问题回报模板.md 报告实际改动、验证证据、未通过/未验证项和下一步；不编造测试结果。需要需求或界面设计协助时提出具体问题并附可查看的材料，由我转交评审，不自行假定有自动通信授权。
~~~

## 二 后续单轮开发任务模板

先替换方括号内容再发送，不原样把未填字段当授权：

~~~text
本轮仅实现：[具体用户场景与阶段/工作包]。
涉及页面/对象：[页面名称、数据对象、角色范围]。
已批准技术与可用环境：[真实配置或资料位置，不填明文秘密]。
允许修改的范围：[明确文件或目录]。
不在本轮范围：[排除项]。
输入和依赖：[已确认材料、接口合同、前置版本]。
必须通过：[正常/异常流程、权限、持久化、引用/格式、必要截图]。
交付：[代码或文档、验证记录、实际截图/日志、未完成项]。

先检查现状，再按上述最小范围实现。对不影响当前任务的待定项记录即可；涉及权限、安全、破坏性操作或重大选型的变化必须说明并取得相应批准。每轮都按交付回报模板报告，不用“后续再接接口”代替本轮承诺的完整功能。
~~~

## 三 给需求与设计评审方的转交句式

~~~text
请评审接手 AI 的本轮结果，先不改业务代码。
任务目标：[本轮目标]。
实际改动：[摘要、绝对文件路径或源码版本]。
证据：[可实际查看的截图、日志或接口结果位置]。
未完成与疑问：[逐项写清]。
希望重点检查：[需求偏离/页面交互/样式规则/接口数据/权限/测试证据]。
请给出阻塞问题、可改进项与下一步建议，不把未验证内容判为通过。
~~~

如需评审方直接修改代码，用户应另行明确范围，先停止同文件的并行编辑。需要向指定 AI 或任务直接发消息时另行授权；这里只提供用户可转交的内容。
