# 06 开发账号与改密（2026-10-11 更新）

按用户要求，当前本地管理员继续使用固定账号 `admin / admin123`。启动不覆盖已有密码，也不再因密码是 `admin123` 自动要求改密。历史回报（`回报/`）按当时情况保留，不再修改。

## 规则

- 空数据库不会自动写入固定账号。第一个管理员由 `cd server && uv run python -m app.bootstrap_admin` 生成随机初始密码（只显示一次），或用 `BOOTSTRAP_ADMIN_*` 环境变量创建；Windows 便携版首次启动自动生成并写入 `初始管理员密码.txt`。已有数据迁移时保留原账号。
- 以下账号登录后必须先改密，改密前除 `/auth/me`、`/auth/logout`、`/auth/change-password` 外的接口都返回 `403 PASSWORD_CHANGE_REQUIRED`，前端会直接跳到“修改密码”页：
  - 新建的第一个管理员；
  - 管理员新建的账号、被管理员重置密码的账号（重置自己的除外）；
- 密码修改、新建与重置的前后端校验统一为 8 至 1024 个字符；修改时不能与当前密码相同。

## 对接手 AI 与验收的影响

1. 当前业务库的 `admin` 已按用户要求恢复为 `admin123` 并解除改密标记，恢复前已备份 SQLite。恢复同时撤销了管理员旧会话，重新登录可直接进入项目。其他账号的密码和临时密码标记不受影响。
2. 新密码只记在本机（例如个人密码管理器或不入库的本地笔记），**不要写进仓库、交接文档或回报**。
3. 忘记密码时，停止后端后在 `server` 目录执行 `uv run python -m app.reset_admin [账号]`（便携版：`文档工作室.exe --reset-admin [账号]`），得到新的随机临时密码，登录后再改。
4. 自动化测试或截图脚本需要登录时，请在独立的 `/tmp` 测试库中用 `app.identity.create_user` 或 `BOOTSTRAP_ADMIN_*` 创建测试账号，不要复用业务库的管理员密码。
