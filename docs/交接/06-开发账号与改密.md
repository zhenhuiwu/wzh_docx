# 06 开发账号与改密（2026-10-10 起生效）

本说明替代旧交接文档中“admin/admin123 未修改、固定登录账号”的说法。历史回报（`回报/`）按当时情况保留，不再修改。

## 规则

- 系统没有默认账号和默认密码。第一个管理员由 `cd server && uv run python -m app.bootstrap_admin` 生成随机初始密码（只显示一次），或用 `BOOTSTRAP_ADMIN_*` 环境变量创建；Windows 便携版首次启动自动生成并写入 `初始管理员密码.txt`。
- 以下账号登录后必须先改密，改密前除 `/auth/me`、`/auth/logout`、`/auth/change-password` 外的接口都返回 `403 PASSWORD_CHANGE_REQUIRED`，前端会直接跳到“修改密码”页：
  - 新建的第一个管理员；
  - 管理员新建的账号、被管理员重置密码的账号（重置自己的除外）；
  - 仍在使用 `admin123` 的任何账号（后端每次启动时检查）。
- 新密码至少 12 位，不能与当前密码相同；所以 `admin123` 不能再被设回去。

## 对接手 AI 与验收的影响

1. 已有开发库里的 `admin` 若还是 `admin123`，合并本分支后第一次启动就会被要求改密。按 AGENTS.md 做 1920×1080 截图验收时，第一次登录会先进入改密页（截图示例：`/workspace/wzh_collab/screens/stabilize-fix/`），改密后再进入业务页面。
2. 新密码只记在本机（例如个人密码管理器或不入库的本地笔记），**不要写进仓库、交接文档或回报**。
3. 忘记密码时，停止后端后在 `server` 目录执行 `uv run python -m app.reset_admin [账号]`（便携版：`文档工作室.exe --reset-admin [账号]`），得到新的随机临时密码，登录后再改。
4. 自动化测试或截图脚本需要登录时，请在独立的 `/tmp` 测试库中用 `app.identity.create_user` 或 `BOOTSTRAP_ADMIN_*` 创建测试账号，不要复用业务库的管理员密码。
