# 438C 技能接入

来源：`server/workspaces/GJB438C-DocSkill/skills/`。

已接入两个 DeepAgents 原生技能：

- `word-fillter-438c-srs`：软件需求规格说明（SRS）。
- `word-fillter-438c-sdd`：软件设计说明（SDD）。

服务端按来源模板、文档名称、编写要求及标题匹配 SRS/SDD，从技能的 `templates/project.json` 提取当前章节规则并直接交给智能体。动态子节沿用最近的父节规则。智能体还通过 `read_file` 阅读对应技能定义及配套 Word 模板正文。未匹配到438C文档时不强行套用其章节。每次生成重新加载资料，修改技能文件后下次生成即可生效。

资料保存在本次智能体的虚拟文件状态中，技能目录禁止写入。原始文件保持不变；资料副本中的示例正文、表格数据和动态子节已清空，避免示例项目被当成当前项目事实。

当前流程按用户选定的标题或文字生成正文，再由现有编辑、保存和 Word 导出流程采用结果。目录中其他文档目前只有模板，尚无专用技能；完整模板填写脚本未接入章节生成流程。

## 格式约束

- JSON 生成、流式生成和采用章节草稿共用正文校验：拒绝 ATX/Setext 标题、重复标题、HTML、代码围栏、JSON、图片、链接、引用块和嵌套列表。允许段落、加粗、斜体、单层列表及矩形表格。选中文字改写使用纯文本。
- 章节表格按技能规定的数量、列数、列顺序校验；已有原稿表头优先保留。禁止多余字段或短行，避免 Markdown 自动截断、补齐单元格。未知数据写“待补充”；已有模板表格使用替换，防止追加重复表格。
- 字体、字号、缩进、行距和页面设置由原 Word 样式控制。新增正文使用附近正文的格式，表格新增数据行复制原数据行；合并表头及目录域保留。
- 采用章节草稿前先对整份编辑稿试导出，确认能应用到原 OOXML 才写入 SQLite。格式校验或导出检查失败时保留原稿。停止后的章节草稿也须经过采用校验。
- 流式内容是候选预览，结束后才执行完整表格校验。模型不合格输出会显示错误，用户可以重新生成；这不代表整份文档已经通过438C内容合规审核。
