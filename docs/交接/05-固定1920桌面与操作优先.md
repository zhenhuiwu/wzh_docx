# 固定1920桌面与操作优先

日期：2026年9月28日。依据：用户最新明确要求，只存在1920×1080固定桌面使用环境，评审重点为界面设计、操作体验和业务逻辑。

## 本轮范围变更

- 只设计和验收1920×1080，不再做375/768/1280/1440适配，不再将手机或平板显示问题列为本项目缺陷。
- 原方案、任务卡、技能或历史报告中的多尺寸要求与本次明确范围冲突时，采用本文件及更新后的AGENTS。历史截图和历史检查记录保留，但不继续驱动响应式开发。
- 本轮优先级是业务任务能否完成、操作是否连续、内容和状态是否清楚、桌面空间是否合理。权限和其他技术问题保留记录，不占本轮界面整改主线；这不表示已修复或验收通过。
- 保留Vue3、现有控件和CSS变量、不展示模板/文档编号、不用假数据或装饰统计卡等既有要求。
- 前端改后仍需在http://localhost:5173实际操作和截图看图，只验1920×1080。固定屏幕并不免除长内容、焦点、错误/空/加载状态与真实按钮行为的检查。

## 接手AI此次应交付什么

不要再交一套能点开很多菜单的页面框架。先交一条能完成的工作过程：选择项目 → 在项目内准备资料 → 选择文档 → 编写与保存具体内容 → 查看依据/修改差异 → 提交审核 → 审核员阅读实际版本后决定 → 生成并查看交付文件。

真实模型或Office环境未配置的步骤要明确阻塞和下一步，不伪造完成；不因此省略其他已经可实现的页面操作。
